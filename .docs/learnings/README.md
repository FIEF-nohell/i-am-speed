# Learnings

Evidence-backed, contextual lessons named `YYYY-MM-DD-<slug>.md`. New files require governance metadata (`id`, `status`, `scope`, `priority`, `owner`, `confidence`, `last-reviewed`) plus `date`, `tags`, `severity`, `applies-to`, `evidence-refs`, `validates-with`, and `invalidates-when`. Superseded learnings are never deleted. The metadata schema and scope grammar are documented in `../rules/README.md`.
